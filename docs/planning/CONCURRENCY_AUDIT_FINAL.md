## 六、性能考量

### 6.1 内存使用

- `runtime` Map: 按会话ID存储，会话删除时自动清理
- `clients` Map: 连接断开时自动清理
- `socketToClientId` Map: 与 clients 同步清理

### 6.2 CPU 使用

- 请求队列: O(1) 入队，O(1) 出队
- 令牌桶: O(1) 检查
- 心跳检测: O(n) 每 heartbeatInterval

### 6.3 锁竞争

- WAL 模式减少写锁阻塞
- 每会话独立队列避免全局锁
